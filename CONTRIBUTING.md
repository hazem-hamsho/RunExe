# Contributing to RunExe
First off, thanks for taking the time to contribute :heart:!

## Found a Problem?
Before reporting a problem, be it a bug, design or others, we assume you have made sure that:
1. the [RunExe wiki](https://github.com/hazem-hamsho/RunExe/wiki) does not cover your problem
1. the problem has not been reported in the [issue tracker](https://github.com/hazem-hamsho/RunExe/issues)
1. the problem is reproducible with the latest RunExe from [this repository](https://github.com/hazem-hamsho/RunExe)

If all apply, then please consider opening a [new issue](https://github.com/hazem-hamsho/RunExe/issues/new/choose).

## Want to Submit Code?
You can submit code by [forking](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks/about-forks) this project, editing the desired code and finally submitting a [pull request](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request).

To build RunExe, refer to the [Building](README.md#Building) instructions.
