# Installers

Installers are ready-made recipes that set up a program inside a capsule:
they create the right environment, install the dependencies it needs and run
the program's setup for you.

1. Open a capsule and go to **Installers**.
2. Pick the program and press **Install**.
3. Follow the program's own setup window if one appears.

Installers come from the
[runexe-programs](https://github.com/hazem-hamsho/runexe-programs) catalog.
Each one has a grade that shows how well the program is known to work.
