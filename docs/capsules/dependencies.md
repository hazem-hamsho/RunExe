# Dependencies

Many Windows programs need extra libraries, fonts or runtimes (for example
Visual C++ redistributables, .NET or DirectX components) that are not part of
Wine.

1. Open a capsule and go to **Dependencies**.
2. Find the dependency the program needs and press the download button.
3. Wait for the installation to finish before starting the program.

Dependencies come from the
[runexe-dependencies](https://github.com/hazem-hamsho/runexe-dependencies)
catalog. Install only what a program actually needs: extra dependencies can
change how other programs in the same capsule behave.
